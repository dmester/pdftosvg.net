# ITU T.803 Conformance test files

To run the JPEG 2000 conformance tests, the conformance test files from ITU are required. For legal reasons, they cannot be included in this repo, but
you can download them free of cost from ITU:

https://www.itu.int/rec/T-REC-T.803/en

Unzip the folder in this folder. The target folder structure should look like this:

```
TestFiles
└── T.803-JPEG2000-conformance
    ├── codestreams_profile0
    ├── codestreams_profile1
    ├── reference_class1_profile0
    └── reference_class1_profile1
```
